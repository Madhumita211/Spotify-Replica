# 🎵 Spotify Replica (Static HTML & CSS)

This project is a **static clone** of the Spotify Web Player UI, built using pure **HTML** and **CSS**. It replicates the layout and design of Spotify’s desktop interface as a practice in static page structuring and visual styling — with no interactivity or responsiveness.

## 🎯 Objective

- Practice building structured layouts using HTML
- Replicate a real-world interface using basic CSS
- Focus on pixel-perfect design without JavaScript or responsiveness

## ✨ Features

- 🎧 Fixed sidebar with Spotify-style navigation
- 🖼️ Playlist layout with album/artwork placeholders
- 🖤 Dark theme mimicking Spotify's branding
- 💡 Static-only interface — no mobile responsiveness, no interactivity

## ⚠️ Note

> This is a **static, desktop-only project**.  
> It does **not** include media playback, responsiveness, JavaScript, or backend features.

## 🚀 Getting Started

1. **Clone the repository**

    ```
   git clone https://github.com/Madhumita211/spotify-replica.git
   cd spotify-replica
    ```
2. **Open `index.html` in any browser**

That's it! No dependencies or server setup required.
